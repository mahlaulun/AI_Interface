🧩 Component Hierarchy

  • ChatView.jsx: Real-time streaming conversation, model dropdown, memory citation tags with jump-to-chat.
  • HistoryView.jsx: Full-screen sortable (date, message count) & filterable (model, topic, query) conversation manager.
  • TopicsView.jsx: Interactive dynamic Word Cloud + aggregated multi-chat AI synthesis.
  • SettingsView.jsx: API key vault & local Ollama endpoint configuration.
  • services/indexer.js: In-memory chunking, topic extraction, and semantic search.
